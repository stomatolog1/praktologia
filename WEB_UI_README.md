# 🎉 Веб интерфейс готов!

## Как запустить:

```bash
cd d:/practica/praktologia
./praktologia.exe
```

Откройте в браузере: **http://localhost:8080**

## 📊 Возможности интерфейса:

### Левая сторона - Формы для добавления данных:
- ✅ **Оборудование** - добавить новое оборудование с ценой и периодом аренды
- ✅ **Исполнители** - зарегистрировать исполнителей/подрядчиков  
- ✅ **Сотрудники** - добавить сотрудников с должностью и зарплатой
- ✅ **Клиенты** - регистрация клиентов с данными компании

### Правая сторона - История создания:
- 📋 Список всех созданных элементов в реальном времени
- 🆔 Каждый элемент получает уникальный ID
- ✨ Красивый UI с уведомлениями об успехе/ошибке

## 🎨 Особенности дизайна:

- 🌈 Современный градиент фон
- 📱 Адаптивный дизайн для мобильных устройств
- 🎯 Удобные вкладки для переключения форм
- 💬 Всплывающие уведомления об успехе операций
- ⚡ Быстрые операции без перезагрузки страницы

## 🔄 Как работает:

1. **Заполняете форму** с данными
2. **Нажимаете кнопку** "Добавить..."
3. **Данные отправляются** на API (`/api/Equipment`, `/api/Executor` и т.д.)
4. **API сохраняет** данные в памяти приложения
5. **Интерфейс обновляется** и показывает созданный элемент в истории

## 📌 Важно:

- Данные хранятся в памяти приложения (при перезагрузке сервера данные теряются)
- Для постоянного хранения нужно подключить БД (PostgreSQL, MySQL и т.д.)
- При первом запуске откройте http://localhost:8080 в браузере
